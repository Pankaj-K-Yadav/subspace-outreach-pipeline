# SubSpace Outreach Pipeline

Automated cold outreach pipeline built for the SubSpace Software Engineering Assignment.

## Workflow

Input Domain
→ Ocean.io
→ Similar Companies
→ Prospeo
→ Decision Makers
→ Eazyreach
→ Verified Emails
→ Brevo
→ Personalized Outreach

## Tech Stack

- Node.js
- Axios
- dotenv
- readline-sync
